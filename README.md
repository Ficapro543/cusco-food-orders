# Cusco Food Orders

Sistema web para gestionar pedidos de comida local en Cusco.

## Descripcion

Este proyecto busca desarrollar una plataforma web que
permita a los usuarios realizar pedidos de platos tipicos
cusquenios de restaurantes locales.

## Tecnologias

- Frontend: HTML, CSS, JavaScript
- Backend: Por definir
